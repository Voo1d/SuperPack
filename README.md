# SuperPack — старт разработки в Claude Code

В папке `prototype/` находится интерактивный визуальный макет. Он не хранит данные: все партии и сотрудники там примеры. При разработке используйте макет как образец интерфейса, а правила учёта из `CLAUDE.md` — как требования к поведению.

## Запуск работы в Claude Code на сайте

1. Распакуйте архив на своём компьютере.
2. Откройте на GitHub репозиторий Super Pack, который подключён в Claude Code.
3. В GitHub выберите `Add file` → `Upload files` и перетащите **содержимое** папки `superpack-claude-starter`: `README.md`, `CLAUDE.md`, `TASK-01.md` и папку `prototype`. Файлы должны оказаться в корне репозитория и в `prototype/`, без дополнительной внешней папки и без ZIP как единственного файла. Сохраните изменения (commit).
4. В веб-версии Claude Code начните новую задачу, выберите этот репозиторий и отправьте: «Прочитай CLAUDE.md и TASK-01.md. Выполни TASK-01.md по этапам; сначала проверь содержимое репозитория. Работай в отдельной ветке, затем подготовь PR в dev».

Если репозиторий уже содержит файлы проекта, сначала посмотрите его структуру и не затирайте существующие исходники при загрузке. При необходимости перенесите правила и макет в подходящие папки, а `CLAUDE.md` оставьте в корне.

Dev-сервер уже настроен на автоматическое получение ветки `dev`, но его таймер пока выключен. Через аккаунт с серверным доступом его можно включить один раз заранее: пока в `dev` нет готового приложения, механизм ждёт код. Каждый последующий коммит в `dev` будет разворачиваться автоматически. При автоматическом откате приложения миграции БД назад не откатываются.

Работайте с другом в отдельных ветках одного Git-репозитория. У каждого должна быть своя сессия Claude Code, чтобы история запросов и авторство коммитов не смешивались. Не размещайте токен Telegram-бота, секреты и `.env` в Git.

## Дальнейшие этапы

1. Основа, доступ Telegram, склад и приёмка — `TASK-01.md`.
2. Производство, палеты, фактический расход сырья, движения и остатки.
3. QR для партий и палет, сканирование и прослеживаемость.
4. Экспорт PNG и PDF, несколько партий в одном PDF с отдельным количеством этикеток; проверить макет на XP-365B.
5. Отгрузка, аналитика, роли и эксплуатационная проверка.

Открытые правила предметной области перечислены в `CLAUDE.md`. Если они влияют на текущую операцию, Claude должен вынести их как выбор для владельца, а не угадывать.
